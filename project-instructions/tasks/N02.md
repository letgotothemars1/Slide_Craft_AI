# N02 — Student test and presentation evidence

**Owner:** non-coding classmates. **Difficulty:** 1/5. **Budget:** 1–2 days including short sessions. **Start:** end of week 2. **Status:** ready after demo route works.

**Outcome:** the course presentation shows what real users could and could not do, rather than only developer claims.

**Do:** ask five to eight master's students to attempt the demo with N01 material, ideally without a developer explaining each step. For each participant, record whether they found the Context Pack instruction, fixed the outline, noticed progressive slides, edited a ready block, found its source, and opened the PPTX. Note task time and confusion in plain language. Do not collect private assignments, names, or conversation logs. Ask one short final question: “Did the staged process give you more control, or did it slow you down?” Summarize recurring problems and select three screenshots or a short screen recording with permission.

**Deliverables:** `project-instructions/TEST_NOTES.md` with an anonymized table of attempts, common blockers, two or three useful quotes, and changes the developers made. Help rehearse the 3–5 minute demo and clearly separate implemented behavior from future ideas.

**Done when:** the team has evidence from at least five users or, if recruitment fails, a clearly labeled smaller formative test plus the reason. No invented user feedback.

**New-chat prompt:** “Help me run N02 from `project-instructions/tasks/N02.md`. I do not code. Make a simple test script and notes table for real participants, then help summarize only the observations I supply.”

**Completion record:** status / date / number of testers / evidence: _fill when done_.
