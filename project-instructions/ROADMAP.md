# SlideCraft AI MVP: единый поток задач на три недели

Этот roadmap показывает порядок работы и зависимости. Исполнители здесь не назначены: любой следующий пункт можно взять как отдельную задачу. Подробные критерии для тикетов T00–T20 и C01–C04 находятся в `EXECUTION_BOARD.md`; продуктовые ограничения — в `START_HERE.md` и `CONTRACT.md`. Для нового чата достаточно передать номер тикета и эти файлы.

## Цель MVP

За один непрерывный сценарий пользователь добавляет задание, Context Pack и один PDF; получает пять черно-белых набросков; исправляет и утверждает их; видит, как слайды становятся готовыми по одному; редактирует отдельный блок, пока создаётся другой слайд; перегенерирует один блок; экспортирует презентацию с редактируемыми текстом и фигурами в PPTX.

Задачи внутри этапа могут идти одновременно после фиксации общего контракта. Переход между этапами определяется работающим результатом, а не только календарём. Основной путь зависимости: **T00 → T01/T04 → T06/T08 → T10/T11 → T13/T15 → T17 → T19/T20**.

## Приоритет при нехватке времени

Сохранить полный путь пользователя: материалы → редактируемый набросок → слайды по одному → локальная правка → редактируемый PPTX. Сначала сократить число макетов до двух и тем до двух; затем делать привязку к странице PDF с ручным выбором. Не подменять реальную поэтапную генерацию только анимацией интерфейса. Не брать в MVP анимации слайдов, свободное перемещение объектов, генерацию картинок, совместную работу и новые дашборды.
